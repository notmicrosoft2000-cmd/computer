Cross-server matchmaking

Fill a Space Mafia crew with players from any server, then play a normal game in a thread on the hub.

What it is

/mm gathers Space Mafia players from every server the bot is in. Anyone who has joined the hub server can queue from wherever they are; once enough players are waiting, the bot opens a public thread in the hub and runs an ordinary game there.

The match itself still plays out in DMs. The only things that cross a server boundary are the queue, the launch and the public status card.

You do not have to share a server with the other players — but you do have to be a member of the hub server, because that is where the match thread lives.

Join the hub server

The hub is the project's support server. Joining costs nothing and only gates matchmaking — the rest of the bot, including ordinary /sus games, works on any server.

The /mm commands

NameSyntaxDescriptionPermissions
/mm queue/mm queue Join the matchmaking queue from any server. Requires membership of the hub server, since the match runs there.anyone (hub member)
/mm status/mm status Show who is queued and how long until launch.anyone
/mm leave/mm leave Drop out of the queue.anyone
/mm cancel/mm cancel Stop a pending launch countdown. Only the first player in the queue can cancel.queue host

Behaviour can change between bot versions; this page mirrors the bot's own documentation.

How a match launches

  1. Queue with /mm queue. You can be anywhere — a server of your own, or a DM channel.
  2. When the fourth player queues, a 45-second countdown starts so stragglers can still join.
  3. At launch the bot opens a public thread on the hub server and DMs everyone their role.
  4. Play an ordinary Space Mafia game. At the end, a rematch button starts another round.
  • Minimum 4 players, maximum 10.
  • If too many players leave before the countdown expires, the countdown folds and the queue waits again.
  • Players who are already in a game are skipped at launch, so you never get pulled into two matches.
  • Two players with the same display name are numbered apart (for example Alex 2).

The lobby console on the Space Mafia page simulates the same seat counts and phases.

Before you queue

  • Join the hub server. /mm queue checks membership before it adds you.
  • Expect a wait. Nothing happens until at least four players are queued. /mm status shows the count and the timer.
  • The queue is in memory. It is not saved, so a bot restart or update empties it — just run /mm queue again.

What crosses servers

Crosses into the hubStays put
The matchmaking queueThe rest of your server
The public launch and status cardYour server's own channels
The public match thread on the hubThe actual play, which happens in DMs
Your display name, for the rosterNothing else — no message history is forwarded

Matchmaking runs the same game engine as a normal /sus match, so kills, meetings and votes behave exactly as they do on your own server.

If something is wrong

I queued, but nothing is happening.

You need at least four queued players. Run /mm status to see the count and the countdown. If the queue looks empty, the bot may have restarted — the queue is only kept in memory, so queue again.

It says I need to be a member of the hub server.

Matches run in a thread on the hub server, so you must be a member there to queue. Join it from the support invite, then try /mm queue again.

The 45-second countdown vanished.

The countdown only starts once the minimum is reached, and it folds if too many players leave before it expires. When that happens the queue simply waits for more players.

My name shows up as “Alex 2”.

Two queued players had the same display name, so the roster numbers them apart to keep the vote menus unambiguous. It only affects the match lobby.

Privacy

Matchmaking adds no new stored data. The queue and the launch are held in memory and are gone when the process ends; a completed match records the same counters as any other Space Mafia game. Nothing from your server is forwarded to the hub beyond the roster name shown in the thread.

Full details are in the Privacy Policy. You can export or erase your game data with /sus export and /sus forget.
