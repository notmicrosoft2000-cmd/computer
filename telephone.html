Telephone

Dial an entire Discord server. Answer, get a busy signal, hang up.

A party line between servers

The /phone system connects whole Discord servers to each other. Each listed server gets a permanent number like #4621-K and a jack — one channel on each side that is wired to the other for the duration of a call.

Someone dials, the other side's channel shows a RIIIING card, anyone (or an admin) picks up, and from then on both channels relay messages between each other until somebody hangs up.

Important: this page cannot place or carry Discord calls. Only the Discord bot, running in your server, implements calling. The interface below is an illustration of the bot's behaviour, not a working telephone.

Looking for the player-to-player ship phone instead? That is the separate /user system — see the ship phone below.

Finding people, answering, and privacy

How servers discover each other

  • The Phone Book — /phonebook lists every server that opted in, with its number and current status.
  • Dial by name or number — /phone dial autocompletes the directory, or takes any #number.
  • Party-line roulette — /phone random wires you to a random server; nobody at the other end parks you in a call-waiting queue.
  • Speed dial — bind slots 1–9 and reach a regular line with a single digit.

How a call is answered

  • A ringing call posts a RIIIING card in the target's jack channel; anyone may pick up.
  • A call stamped OFFICIAL BUSINESS can only be answered by admins there.
  • Party-house mode (/phone settings autoanswer:true) connects ordinary calls instantly.
  • Either side ends the call with the HANG UP button or /phone hangup.

How privacy is protected

  • Nothing is listed until an admin accepts the rules and privacy gates — no name, number or dial tone before consent.
  • Incoming messages are screened per-category for slurs, profanity, links and GIF/video links; all filters ship ON and are optional.
  • Mentions are stripped crossing the wire, so a call cannot ping strangers.
  • Admins can block a server, set do-not-disturb, or leave the network entirely with /phone data forget.
  • Call logs, reports and voicemails follow published retention windows and can be exported or erased.

Read the full rules in the Terms and the data practices in the Privacy Policy.

The player-to-player ship phone

Not to be confused with the cross-server line. The /user phone calls one person to another by DM using a 4-digit ship extension.

  • /user phone — get your own extension.
  • /user call numero:#4271 — ring someone; they answer or decline with a button.
  • /user hangup — end the call.
  • Every account has a profile that follows you across servers the bot is in.

House rules for a public wire

  • No slurs, ever. Keep it clean by default.
  • No links or GIFs unless the receiving server opted out of that filter.
  • Respect do-not-disturb, blocks and filter receipts.
  • Do not flood a line; there is a short per-person cooldown.
  • OFFICIAL BUSINESS stays admin-only.

Each server enforces the etiquette house by house, so nobody has to be the bad guy.
