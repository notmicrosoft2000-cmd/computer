Server-side environment variables

For a self-hosted bot, tuning lives in .env. These are the documented knobs:

VariableDefaultEffect
SUS_KILL_COOLDOWN30Seconds between impostor kills.
SUS_DISCUSSION60Meeting chat seconds before voting.
SUS_VOTING45How long vote menus stay open.
SUS_TRAVEL6Seconds per room-to-room hop.
SUS_PHONE_LIMIT400Cross-server message length cap.
SUS_PHONE_COOLDOWN3Seconds between relayed messages per person.
SUS_PHONE_RING90Seconds before an unanswered call times out.
SUS_PHONE_IDLE0Silence before a live call auto-hangs up (0 = never).
SUS_AI_ENABLEDtrueNetwork-wide kill switch for AI meeting chat.
