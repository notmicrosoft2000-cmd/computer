Cross-server matchmaking

/mm gathers Space Mafia players from every server the bot is in. Anyone who has joined the hub server can queue from wherever they are; once enough players are waiting, the bot opens a public thread in the hub and runs an ordinary game there.

The match itself still plays out in DMs, so the only thing that crosses servers is the queue, the launch and the public status card. The queue lives in memory — a bot restart clears it.

NameSyntaxDescriptionPermissions
/mm queue/mm queue Join the matchmaking queue from any server. Requires membership of the hub server, since the match runs there.anyone (hub member)
/mm status/mm status Show who is queued and how long until launch.anyone
/mm leave/mm leave Drop out of the queue.anyone
/mm cancel/mm cancel Stop a pending launch countdown. Only the first player in the queue can cancel.queue host

Minimum 4 players, maximum 10. When the fourth player queues, a 45-second countdown starts so stragglers can still join; if too many leave before it expires, the countdown folds. Players already in a game are skipped at launch, and two players with the same display name are numbered apart (for example Alex 2).

Server-side environment variables

For a self-hosted bot, tuning lives in .env. These are the documented knobs:

VariableDefaultEffect
SUS_KILL_COOLDOWN30Seconds between impostor kills.
SUS_DISCUSSION60Meeting chat seconds before voting.
SUS_VOTING45How long vote menus stay open.
SUS_TRAVEL6Seconds per room-to-room hop.
