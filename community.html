Contributing

Help with the website is welcome. Keep changes small, readable and in keeping with the Windows 7 desktop theme.

  1. Open an issue describing the problem or idea, or fork the website repository and make a branch.
  2. Build with the real 7.css components. Do not replace the Aero window frames, gradients and system controls with modern styles.
  3. Use semantic HTML, label your controls, keep keyboard focus visible, and keep contrast readable.
  4. Keep JavaScript light and vanilla — no framework for what CSS and a few lines can do.
  5. Never add secrets, tokens or personal data to the site. Mark any simulation clearly as simulated.
  6. Open a pull request and describe what changed and why.
